"Pandora 18k" database

1. Database description may be retrieved from the following paper (please cie if you use it)
 C. Florea, C. Toca, F. Gieske ”Artistic Movement Recognition by Boosted Fusion of Color 
  Structure and Topographic Description”, in IEEE Winter Application on Computer Vision,
Santa Rosa, CA, USA, 2017

2. The data reported in this paper is found in this archive
 - the lables and the appartenence of an image to an fold are showed in "pandoraLabels.mat"
 - the actual value of an descriptor for image is to be retrieved from the specified .mat file

3. Actual images: the images are collected from Internet. While some are in the public domain, 
some are covered by copyrights. Plese use the image only for data mining/machine learning tasks.
